# ⛓️ ChainScope v1.0.0

**ChainScope** is an advanced Blockchain Intelligence platform built with Python, designed to analyze and audit Ethereum wallets while tracking suspicious behavioral patterns.

## 🚀 Features
* **Wallet Analysis:** Accurately fetches wallet balances and complete transaction history.
* **Security Audit:** Detects potential vulnerabilities and threats such as **Wash Trading** and **Dusting Attacks**.
* **Visual Reports:** Generates highly organized, beautifully formatted statistical reports directly in the terminal using the `rich` library.
* **Success Rate Tracking:** Calculates transaction success rates and analyzes execution failures.

## 🛠️ Technical Requirements
* Python 3.10+
* Required Dependencies: `requests`, `pandas`, `rich`, `python-dotenv`

## 📦 Installation & Usage

1. Clone the repository:
   ```bash
   git clone [https://github.com/main7789/chainscope.git](https://github.com/main7789/chainscope.git)

2. Install the required dependencies: 
pip install -r requirements.txt

3. Run the analyzer: 
python src/main.py
